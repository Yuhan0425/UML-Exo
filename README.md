# Hospital Management System - UML Design

Web platform where patients submit health problems, an organizer (also admin) relays them to doctors, sends prescriptions back, and handles payments.

## Contents
- [Class diagram](docs/class-diagram.md)
- [Sequence diagrams](docs/sequence-diagrams.md)
- [Design questions](docs/design-questions.md)

## Workflow
1. Patient posts a health problem
2. Organizer reads it and consults a doctor
3. Doctor writes a prescription
4. Organizer sends the prescription to the patient
5. Patient pays (check / cash / credit card)
6. Organizer forwards the payment to the doctor
